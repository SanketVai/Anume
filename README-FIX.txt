# Hi Doctor! — fixed preview bundle

IMPORTANT: Extract this ZIP first. For the easiest preview, open `sanket-doctor-standalone.html` — it has its CSS, JavaScript, and images embedded, so the character images will not break due to relative file paths.

For editing the project, open `index.html` from the extracted folder (keep `style.css`, `script.js`, and the `assets` folder beside it).

The form does not send or store answers until you configure a form endpoint in `script.js`. Test with your own dummy submission before sharing.
